## 一、职责范围与交付总览

本模块负责 GameWiki 的 **管理端前端与后台业务接口体系**，覆盖从后台视觉交互、权限控制、组件封装到 REST API、业务服务与 MySQL 扩展表设计的全链路实现：

| 维度 | 核心交付规模 | 说明 |
| --- | --- | --- |
| 管理端页面 | **10 个 `.vue` 页面**（共 3,939 行） | 涵盖总览、游戏管理、攻略管理/审核台、攻略编辑器、用户管理/详情/等级、管理员信息、系统设置与无权限页 |
| 布局与权限体系 | `AdminLayout.vue` + 路由守卫 + **17 项细粒度权限** | 深色后台外壳、侧栏折叠、面包屑、全局搜索、待审核通知、401/403 统一拦截 |
| 公共组件与 API 封装 | **7 个后台组件** + **5 个 API 客户端模块** | ECharts 图表、原生 Dialog、分页器、统计卡、异步游戏选择器、XSS 过滤 Markdown 预览与目录跳转 |
| 后台业务接口 | **`CatalogAdminController` 42 个后台管理接口** + **`CatalogFilesController` 6 个媒体与导入导出接口** | 统一前缀 `/api/admin/v1`，全部受 `@RequireRole("ADMIN")` 保护（媒体读取 `/catalog/media/{id}` 公开缓存） |
| 共享目录与服务层 | **4 个核心目录服务** + **15 个玩家端 `/api/catalog/*` 统一接口** | 打通管理端发布/审核结果与玩家端浏览/收藏/投稿的 MySQL 数据一致性 |
| 数据库扩展脚本 | **`02_shared_catalog.sql`（15 张扩展表）** | 目录字典、游戏/攻略扩展字段、用户档案、等级规则、管理员偏好、操作审计日志、封禁日志、媒体与导入导出任务 |

### 2.2 各页面功能拆解

#### 1. 后台总览（`Dashboard.vue`）
- **核心指标**：展示游戏总数、攻略总数、用户总数、内容总量及近 7 日增量变化，并高亮待审核攻略提醒，点击可直达审核台。
- **数据可视化**：复用 `AdminChart.vue` 渲染 7/30/90 天游戏与攻略新增趋势折线图、游戏主分类占比环形图。
- **运营动态与监控**：提供最新游戏/最新攻略/最新用户切换列表、管理员操作审计日志（`admin_activity`）及 API/数据库健康状态展示。

#### 2. 游戏管理（`GameManage.vue`）
- **检索与分页**：服务端关键词检索（名称/原名/英文名/别名/厂商/标签）、主分类/平台/厂商/状态组合筛选、按名称/发行日/评分/创建时间排序及分页。
- **资料维护与状态机**：支持新增、详情、编辑（含乐观锁版本号 `version` 校验）、封面与背景图上传（前端格式+魔数校验 + 后端落库），以及 `DRAFT` ↔ `PENDING_REVIEW` → `PUBLISHED` ↔ `OFF_SHELF` 状态流转与软删除保护（有关联攻略禁止删除）。
- **批量操作与导入导出**：支持多选批量发布、下架、删除、追加标签、重设分类（返回逐条成功/失败明细）；支持 CSV/XLSX 批量导入（1–1000 条，自动统计成功/失败/重复并生成错误报告）以及按勾选或当前筛选条件导出游戏数据。

#### 3. 攻略管理、审核台与分类标签（`GuideManage.vue`）
- **三视图路由切换**：
  - `/admin/guides`：全量攻略管理，支持搜索、关联游戏/分类/标签/状态筛选、排序、分页、正文预览、复制副本、下架、删除以及 JSON 批量导入导出。
  - `/admin/guides/reviews`：**攻略审核台**，聚焦待审核队列与已发布攻略的修订版本，支持查看正文、批准发布（`approve`）或填写驳回原因退回（`reject`）。
  - `/admin/guides/categories`：维护 `guide_taxonomy` 中的攻略分类与标签字典，支持新增与删除。

#### 4. 攻略编辑器（`GuideEditor.vue`）
- **结构化表单**：维护标题、所属游戏（`GuideGameSelect` 异步防抖搜索）、分类、多标签、简介、封面上传、剧透标记与 Markdown 正文。
- **安全预览与目录**：通过 `GuideMarkdown.vue`（`marked` + `DOMPurify`）实时渲染过滤后的 HTML 并提取标题生成可点击跳转目录；支持正文内插图上传。
- **版本与工作流**：支持保存草稿与提交审核；对已发布攻略再次编辑时生成修订关联记录（`revision_of`），经审核通过后更新线上版本。

#### 5–7. 用户管理、详情面板与等级规则（`UserManage.vue`、`UserDetail.vue`、`UserLevel.vue`）
- **用户治理列表**：支持关键词搜索、角色/会员/账号状态筛选与服务端分页，支持查看详情、修改用户昵称、封禁（填写原因与过期时间/永久）与解封、管理员密码重置（支持自定义或随机生成 10 位密码并仅返回一次明文）。
- **用户分析看板**：展示用户总量/近 7 日新增/近 7 日活跃/VIP 数/封禁数指标卡、7/30/90 天注册增长折线图、会员构成环形图及贡献活跃排行榜。
- **子面板**：`UserDetail.vue` 展示基础资料、按权限脱敏的邮箱与完整封禁/解封审计日志（`user_ban_log`）；`UserLevel.vue` 展示平台 5 级成长规则（`user_level_rule`）。

#### 8–10. 管理员信息、系统设置与无权限页（`AdminProfile.vue`、`SystemSettings.vue`、`AdminAccess.vue`）
- `AdminProfile.vue`：读取 `/api/admin/v1/session` 展示当前管理员名称、角色、17 项权限明细及各后台模块直达入口。
- `SystemSettings.vue`：通过 `/api/admin/v1/preferences` 读写管理员个性化偏好（侧栏默认折叠、表格默认每页 20/50/100 条、总览默认 7/30/90 天周期），变更后通过响应式状态即时应用到全局后台页面。
- `AdminAccess.vue`：统一承接路由守卫与接口响应触发的 401（会话过期）、403（无管理员权限）及服务不可用场景，提供返回首页或重新登录入口。

## 三、布局、公共组件与前端 API 封装

### 3.1 统一布局与权限守卫
- **布局外壳**（`frontend/src/layouts/AdminLayout.vue`、`admin.css`）：根据 `hasAdminPermission` 动态渲染可见导航项；顶栏提供侧栏切换、动态面包屑、跨模块全局搜索框、待审核攻略通知入口、全屏切换及管理员账户菜单（含安全登出）。
- **路由守卫**（`frontend/src/router/index.js`）：访问 `/admin/**` 前自动拉取 `/api/admin/v1/session` 与 `/api/admin/v1/preferences`，结合路由 `meta.adminSection` 与 `meta.adminPermission` 校验权限；运行期遇到 401 自动清空会话并跳转 `/admin/access?reason=401`。

### 3.2 7 个后台通用组件（`frontend/src/components/admin/`）
| 组件 | 职责说明 |
| --- | --- |
| `AdminChart.vue` | 封装 ECharts 实例初始化、深色主题提示框配置、`ResizeObserver` 自适应缩放与卸载销毁 |
| `AdminDialog.vue` | 封装原生 `<dialog>` 模态框，统一处理标题/正文/页脚插槽、Esc 取消与关闭状态同步 |
| `AdminGameIcon.vue` | 内联 SVG 游戏手柄图标，随父容器字号与颜色自适应 |
| `AdminPager.vue` | 通用服务端分页组件，支持页码折叠省略、上下页切换、快速跳页与每页条数切换 |
| `AdminStats.vue` | 统一后台指标统计卡，支持图标、配色主题、总量、7 日增量与周期说明展示 |
| `GuideGameSelect.vue` | 攻略编辑与筛选用的游戏异步搜索下拉框，内置防抖与 `AbortController` 请求防竞态 |
| `GuideMarkdown.vue` | 基于 `marked` + `DOMPurify` 的安全 Markdown 预览器与自动目录锚点跳转组件 |

### 3.3 前端 API 客户端封装（`frontend/src/api/admin/`）
- `client.ts`：创建 `/api/admin/v1` 专用 Axios 实例，自动注入 `Authorization` token，统一校验 `{ code, message, data }` 响应契约、转换 401/403/404/409/5xx 中文提示、管理 `adminSession` 缓存与权限查询。
- `dashboard.ts` / `game.ts` / `guide.ts` / `user.ts`：为四大管理模块提供强类型请求封装、响应字段运行时校验、`AbortSignal` 取消支持及开发态本地演示模式降级。

### 4.2 `CatalogFilesController`（媒体上传与游戏批量导入导出，6 个路由方法）

| 方法 | 路径 | 权限 | 功能说明 |
| --- | --- | --- | --- |

| `POST` | `/api/admin/v1/imports/games` | `ADMIN` | 解析 ≤10 MB 的 CSV/XLSX 文件（1–1000 行），逐行落库并统计成功/失败/重复数 |
| `GET` | `/api/admin/v1/{imports\|exports}/games/{id}` | `ADMIN` | 查询当前管理员发起的导入/导出任务进度与汇总结果（校验任务归属） |
| `GET` | `/api/admin/v1/{imports\|exports}/games/{id}/download` | `ADMIN` | 下载导入错误报告或导出结果数据（校验任务归属） |

### 4.3 共享目录服务层与玩家端接口统一

- **`CatalogDatabase.java`**：封装 `JdbcTemplate` 查询、参数过滤构建器 `Filter`、字段类型归一化、JSON 序列化及操作日志记录。
- **`CatalogGameService.java` / `CatalogGuideService.java` / `CatalogUserService.java`**：封装游戏、攻略与用户的共享读写、状态流转、审核修订、自动解封过期账号、统计聚合与审计日志写入。
- **`CatalogController.java`（`/api/catalog/*`，15 个接口）**：提供玩家端统一的游戏/攻略浏览、筛选字典、攻略投稿、个人资料读写、游戏/攻略收藏、点赞、关注作者与浏览历史管理，确保后台管理变更实时反映到前台。

## 五、数据库扩展设计（`database/02_shared_catalog.sql`）

在 `00_init.sql` 与 `01_like_history.sql` 之上，通过幂等脚本 `02_shared_catalog.sql` 新增 **15 张扩展表**，由 Spring Boot 启动时自动执行：

| 表名 | 用途 |
| --- | --- |
| `catalog_category` / `catalog_platform` | 游戏分类与平台标准字典表（带展示排序） |
| `catalog_game` | 游戏目录扩展表（原名、英文名、别名、厂商/开发商、多分类/多平台/标签 JSON、状态、乐观锁版本与软删除时间） |
| `catalog_guide` | 攻略扩展表（标签、封面、剧透/精选标记、发布与审核时间、驳回原因、修订来源 `revision_of`） |
| `guide_taxonomy` | 攻略分类与标签维护表 |
| `user_profile` | 用户扩展档案表（头像、联系信息、简介、会员类型、经验值、最近登录时间、封禁截止时间） |
| `user_game_favorite` / `user_follow` | 玩家收藏游戏与关注作者关系表 |
| `user_level_rule` | 5 级用户成长等级与经验规则表 |
| `admin_preference` | 管理员界面偏好持久化表（侧栏状态、分页条数、总览周期） |
| `admin_activity` | 后台管理操作审计日志表 |
| `user_ban_log` | 用户封禁/解封历史审计记录表 |
| `catalog_media` | 后台上传图片存储表（UUID、MIME 类型、二进制内容） |
| `catalog_transfer` | 游戏批量导入/导出任务状态与结果载荷表 |
| `catalog_seed` | 基线样本数据一次性初始化标记表（防止重启覆盖管理员后续编辑） |
