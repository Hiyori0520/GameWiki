## 1. 分层职责

```
controller  →  只做参数接收、调用 service、返回 Result，不写业务判断
service     →  业务逻辑、事务、缓存，出错直接 throw BizException
mapper      →  数据访问，继承 BaseMapper<T>
entity      →  与数据库表一一对应，不加业务注解
dto         →  接口入参对象，校验注解写在这里
```

**反例**：Controller 里写 `if (user == null) return Result.error("用户不存在")` —— 违反，改成 `throw new BizException("用户不存在")`。

## 2. 返回结构

一律返回 `Result<T>`，字段是 `code / message / data`（**不是 `msg`**）。

```java
return Result.success(data);                    // 200 + message=success
return Result.success("投稿成功", data);         // 200 + 自定义提示
```

失败**不要**在 Controller 里 return，直接抛异常，交给全局处理器：

```java
throw new BizException("该用户名已被注册");           // 400
throw new BizException(ErrorCode.FORBIDDEN);       // 403
throw new BizException(ErrorCode.NOT_FOUND, "攻略不存在");  // 404
```

## 3. 参数校验

请求参数用 DTO 接，校验注解写在 DTO 字段上：

```java
@Data
public class GuideCreateRequest {
    @NotNull(message = "所属游戏不能为空")
    private Long gameId;

    @NotBlank(message = "标题不能为空")
    @Size(max = 150, message = "标题最多 150 字")
    private String title;
}
```

Controller 加 `@Valid`：

```java
@PostMapping
public Result<GameGuide> create(@Valid @RequestBody GuideCreateRequest request) { ... }
```

校验失败自动返回 `400 + 具体提示`，不用自己判空。**注意**：给 `@RequestBody` 加 `@Valid` 才有用，忘了加注解等于没写。

## 4. 分页（重点，B 一定会用到）

**查询参数**继承 `PageQuery`：

```java
@Data
public class GuideQuery extends PageQuery {   // 自动获得 page / size，含边界保护
    private Long gameId;
    private String keyword;
}
```

**Controller**：

```java
@GetMapping
public Result<PageResult<GameGuide>> list(GuideQuery query) {
    return Result.success(gameGuideService.pageGuides(query));
}
```

**Service**：

```java
public PageResult<GameGuide> pageGuides(GuideQuery query) {
    LambdaQueryWrapper<GameGuide> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(GameGuide::getAuditStatus, 1);
    if (query.getGameId() != null) {
        wrapper.eq(GameGuide::getGameId, query.getGameId());
    }
    if (StringUtils.hasText(query.getKeyword())) {
        wrapper.like(GameGuide::getTitle, query.getKeyword());
    }
    wrapper.orderByDesc(GameGuide::getCreateTime);

    Page<GameGuide> page = query.toPage();      // 已做 page>=1、size<=100 保护
    this.page(page, wrapper);
    return PageResult.of(page);                 // 转成 records/total/page/size
}
```

**必须注意**：`pom.xml` 里已注册分页拦截器（`MybatisPlusConfig`），`this.page(page, wrapper)` 才会真正加 `LIMIT`。如果发现查询把全表捞出来了，先检查这个 Bean 是否被误删。

返回的 JSON 固定是：

```json
{ "code": 200, "message": "success",
  "data": { "records": [], "total": 42, "page": 1, "size": 10 } }
```

## 5. 权限

```java
@RequireRole("ADMIN")        // 只允许管理员
@DeleteMapping("/{id}")
public Result<Boolean> delete(@PathVariable Long id) { ... }
```

默认所有 `/api/**` 都需要登录，只有 `WebMvcConfig` 白名单里的（登录、注册）放行。**新增公开接口必须去 `WebMvcConfig` 加排除，否则前端会拿到 401。**

取当前登录人：

```java
Long userId = UserContext.requireUserId();   // 不要信任前端传的 userId
```

## 7. 提交前自查

| 检查项 | 说明 |
| --- | --- |
| 能启动 | `mvn -f backend/pom.xml spring-boot:run` 无报错 |
| 无明文密钥 | 密码、API Key 只写在 `application-local.yml` |
| 接口有文档 | `@Tag` / `@Operation` 写了没 |
| 返回结构对 | 是 `message` 不是 `msg`；分页是 `records/total` |
| 时间格式 | 不要自己 `toString()`，`LocalDateTime` 已全局配成 `yyyy-MM-dd HH:mm:ss` |
| 不提交垃圾 | `target/`、`node_modules/`、IDE 配置 |
