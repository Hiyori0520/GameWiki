## 二、页面详细说明

### 1. 首页 `/`

**文件**：`frontend/src/views/user/Home.vue`
**定位**：站点入口，承接「找游戏」与「找攻略」两条主路径。

**页面结构（自上而下）**

1. 顶部主视觉区：站点大标题与标语、两个入口按钮（浏览游戏库 / AI 助手）、右侧装饰图区
2. 搜索区：标题「寻找你需要的游戏攻略」、关键词输入框（支持回车）与搜索按钮
3. 热门游戏区：4 张游戏卡片，按评分展示，右上角「查看全部 →」跳游戏库
4. 最新游戏攻略区：3 条攻略条目，带攻略分类、所属游戏、作者、阅读量
5. AI 助手引导区：一句引导文案 + 进入 AI 助手按钮

**交互说明**

| 操作 | 结果 |
| --- | --- |
| 输入关键词后回车或点「搜索」 | 跳转 `/games?keyword=关键词`；关键词为空时跳 `/games` 不带参数 |
| 点击游戏卡片 | 跳转 `/games/:id` |
| 点击「查看全部」 | 跳转 `/games` |
| 点击攻略条目 | 跳转 `/guides/:id` |
| 点击 AI 入口 | 跳转 `/ai/chat`（该页由 A 实现） |

**数据来源**：组件内 `games` 数组（4 款）与 `guides` 数组（3 篇攻略），均为演示数据。

---

### 2. 游戏库 `/games`

**文件**：`frontend/src/views/user/GameList.vue`
**定位**：全站游戏检索页，支持关键词、类型、标签筛选，排序与分页。

**功能点**

| 功能 | 说明 |
| --- | --- |
| 关键词搜索 | 匹配游戏名、简介与标签；支持从 URL 查询参数 `keyword` 初始化；搜索后把关键词写回 URL，便于分享与刷新保持 |
| 类型筛选 | 单选，固定 5 类（角色扮演 / 动作冒险 / 冒险解谜 / 开放世界 / 策略模拟）+「全部」 |
| 标签筛选 | 单选，固定 8 个标签（剧情 / 冒险 / 战斗 / 探索 / 解谜 / 策略 / 经营）+「全部」，与类型筛选叠加生效 |
| 排序 | 最新收录（按收录日期倒序）/ 攻略数量（降序）/ 游戏名称（中文拼音序），三选一 |
| 分页 | 每页 6 条，上一页 / 页码 / 下一页 |
| 重置 | 一键清空关键词、类型、标签、排序与页码，同时清掉 URL 查询参数 |
| 空结果 | 显示空状态提示与「重置筛选」按钮 |

**关键实现**

- `keyword`、`category`、`selectedTag`、`sortBy`、`currentPage` 五个 `ref` 共同驱动 `computed` 的过滤结果
- 筛选条件变化时通过 `watch` 将 `currentPage` 重置为 1，避免停留在越界页码
- 监听 `route.query.keyword`，首页带参数进入或地址栏变化时同步搜索框内容
- 排序使用了 `Array.prototype.sort`，其中名称排序用 `localeCompare(name, 'zh-CN')` 保证中文顺序合理

**数据来源**：组件内 `games` 数组，字段含 `id`、`name`、`category`、`description`、`tags`、`guides`（攻略数量）、`date`（收录日期）、`cover`。

### 3. 游戏详情 `/games/:id`

**文件**：`frontend/src/views/user/GameDetail.vue`（约 1070 行）
**定位**：单款游戏资料页，同时作为进入该游戏所有攻略的入口。

**页面结构**

1. 面包屑：首页 / 游戏库 / 当前游戏名
2. 顶部信息区：封面色块（含符号与水印）、游戏名、类型、简介、标签
3. 数据条：用户评分、攻略数量、平均时长、发行日期
4. 操作区：收藏游戏（☆ / ★ 两态）、写攻略（跳管理端编辑器，仅演示用）、问问 AI 助手（跳 `/ai/chat`）
5. 主体两栏
   - 左栏：游戏简介分段正文、相关攻略列表（支持按攻略分类二次筛选）
   - 右栏：游戏信息卡（开发商、发行商、平台、语言、发售日期）、相关推荐（同类型优先）
6. 找不到游戏时：显示兜底空状态与「返回游戏库」

**交互说明**

| 操作 | 结果 |
| --- | --- |
| 点击「收藏」 | 按钮变为「已收藏」并切换配色（当前仅页面内状态，未持久化） |
| 点击攻略分类标签 | 过滤下方攻略列表，切换游戏时自动重置为「全部」 |
| 点击攻略条目 | 跳转 `/guides/:id` |
| 点击右侧推荐游戏 | 跳转对应 `/games/:id`，并重置页面内筛选与收藏状态 |

**数据说明**：8 款游戏，`id` 为 1~8；每款游戏挂 1~4 篇攻略，攻略 `id` 与攻略详情页数据一一对应（101/102/103/104、201/202、301/302/303、401/402、501/502、601/602/603、701、801/802）。

### 4. 攻略详情 `/guides/:id`

**文件**：`frontend/src/views/user/GuideDetail.vue`（约 2220 行）
**定位**：图文攻略阅读页，是全站内容消费的终点页。

**页面结构**

1. 顶部阅读进度条：随页面滚动增长，进度为 0 时自动隐藏
2. 面包屑：首页 / 游戏库 / 游戏名 / 攻略分类
3. 文章头部：游戏封面色块（可点回游戏详情）、分类标签、标题、摘要、作者头像与身份、发布时间、更新时间、预计阅读时长、浏览量
4. 操作栏：收藏攻略、点赞（带计数）、复制链接、字号三档（A− / A+）
5. 正文区
   - 按章节分段，每章带两位序号标题
   - 支持三种内容块：普通段落、有序步骤列表、蓝色左边框提示框
   - 正文末尾：话题标签行、作者结语
   - 底部：上一篇 / 下一篇（跨游戏按数据顺序串联，无上一篇时显示占位）
6. 右侧栏（sticky）
   - 章节目录：滚动时自动高亮当前章节，显示阅读百分比，点击平滑滚动到对应章节
   - 作者卡：头像、身份、相关攻略数、获赞数、关注按钮
   - AI 辅助卡：跳转 `/ai/chat` 并携带 `q` 参数（当前攻略标题预填）
   - 相关攻略：同游戏优先，不足时用其他游戏补齐，共 3 条
7. 找不到攻略时：显示兜底空状态与「去游戏库看看」

**关键实现**

- 滚动监听用 `window.addEventListener('scroll', ..., { passive: true })`，在 `onBeforeUnmount` 中移除，避免路由切换后残留监听
- 当前章节判定：遍历各章节 `getBoundingClientRect().top <= 150` 的最后一个
- 收藏写入 `localStorage`，键名 `gamewiki_guide_collected`，值为攻略 id 数组；读取时做 `Array.isArray` 与类型校验，存储不可用时静默降级
- 点赞只在本页生效（`likes + 1`），未持久化
- 切换攻略（`route.params.id` 变化）时重置点赞、字号，并回滚到页面顶部
- 复制链接使用 `navigator.clipboard`，失败时提示手动复制

**数据说明**：19 篇攻略，`id` 覆盖 101~802，与游戏详情页的攻略列表严格对应，每篇 3~4 个章节。

### 5. 个人中心 `/profile`

**文件**：`frontend/src/views/user/Profile.vue`（约 1175 行）
**定位**：当前登录用户的资料、收藏与浏览记录。

**页面结构**

1. 用户卡片：头像（昵称首字缩写）、昵称、`@登录名`、等级、身份标签、个人简介，右侧三个按钮「编辑资料 / 去游戏库 / 退出登录」
2. 卡片底部四项统计条：我的收藏、浏览记录、发布攻略、获得点赞
3. 三个标签页
   - **个人资料**：只读信息网格（昵称、账号、邮箱、手机、所在地、注册时间、简介）；点「编辑资料」切换为表单，底部为「取消 / 保存」
   - **我的收藏**：顶部两个子标签「攻略 / 游戏」，默认攻略
     - 攻略：纵向列表卡片，含所属游戏封面色块、攻略分类、标题、游戏名、作者、阅读时长、更新时间、阅读量，点击进入攻略详情，可取消收藏
     - 游戏：3 列游戏卡片，可取消收藏，收藏数联动标签标题与统计
   - **浏览历史**：游戏与攻略混排，倒序展示，带类型徽章与时间，点击跳对应详情页
4. 页面底部居中的保存提示条（轻提示，约 2 秒后自动消失）

**交互说明**

| 操作 | 说明 |
| --- | --- |
| 编辑资料 | 可编辑昵称、邮箱、手机、所在地、简介五项，写入独立的 `draft` 草稿对象，点「取消」丢弃改动并回填原值 |
| 保存 | 校验昵称非空（为空时直接返回，不保存），保存后弹出提示，明确告知当前为本地数据、接口接入后同步后端 |
| 登录账号 | 只读展示，不提供编辑入口 |
| 切换攻略 / 游戏 | 两个子标签，默认「攻略」；子标签上的数字实时反映各自数量 |
| 取消收藏（攻略） | 从列表移除，同时写回 `localStorage`，攻略详情页再次打开时收藏状态同步为未收藏 |
| 取消收藏（游戏） | 从列表移除，同步更新计数；全部取消后显示空状态 |
| 清空历史 | 二次确认（确定 / 取消），确认后清空并显示空状态 |
| 退出登录 | 跳转 `/auth`（登录逻辑由 A 实现，当前未做真实登出） |

**数据说明**：演示用户为 `lijunhui50` / `wtltwzlz@163.com`，昵称「网络无响应」；收藏 3 篇攻略 + 4 款游戏（攻略 id 103、301、501；游戏 id 1、3、5、6），浏览历史 7 条（4 条游戏 + 3 条攻略）。

**收藏机制说明**

- 收藏以**攻略为主**：站点定位是攻略知识库，用户会反复回看的是攻略，游戏资料看一次即可
- 攻略收藏与攻略详情页共用 `localStorage` 键 `gamewiki_guide_collected`（值为攻略 id 数组），形成「攻略页收藏 → 个人中心查看 → 点回攻略」的闭环
- 首次进入个人中心时若本地没有收藏记录，会写入 3 条演示数据（103、301、501），保证演示时页面不空；用户手动清空后不会再自动填充
- 攻略数据来自 `src/data/guides.ts`，与攻略详情页共用同一份数据，避免两处维护
- 两个页面都监听 `storage` 事件：一个标签页里取消收藏，另一个标签页的状态同步更新，无需刷新
- 游戏收藏保留，作为辅助功能放在第二个子标签

## 三、页面跳转关系

```text
首页 /
├── 搜索 ──────────────→ 游戏库 /games?keyword=xxx
├── 游戏卡片 ──────────→ 游戏详情 /games/:id
├── 攻略条目 ──────────→ 攻略详情 /guides/:id
└── AI 入口 ───────────→ AI 助手 /ai/chat

游戏库 /games
└── 游戏卡片 ──────────→ 游戏详情 /games/:id

游戏详情 /games/:id
├── 攻略条目 ──────────→ 攻略详情 /guides/:id
└── 推荐游戏 ──────────→ 游戏详情 /games/:id

攻略详情 /guides/:id
├── 游戏名 / 封面 ─────→ 游戏详情 /games/:id
├── 上一篇 / 下一篇 ───→ 攻略详情 /guides/:id
├── 相关攻略 ──────────→ 攻略详情 /guides/:id
└── AI 提问 ───────────→ AI 助手 /ai/chat?q=预填问题

个人中心 /profile
├── 收藏的攻略 ────────→ 攻略详情 /guides/:id
├── 收藏的游戏 ────────→ 游戏详情 /games/:id
└── 历史记录 ──────────→ 游戏详情 /games/:id 或 攻略详情 /guides/:id
```

## 四、前端数据结构（TypeScript 定义）

以下为页面当前使用的字段，可直接作为后端返回结构的依据。

### 4.1 游戏（列表项）

```ts
interface GameListItem {
  id: number
  name: string
  category: string        // 游戏类型，如「角色扮演」
  description: string     // 一句话简介
  tags: string[]          // 标签，如 ['剧情', '冒险']
  guides: number          // 攻略数量
  rating: number          // 评分，一位小数
  cover: string           // 封面配色标识，见 4.5
  symbol: string          // 封面符号字符
}
```

### 4.2 游戏（详情）

```ts
interface GameDetail extends GameListItem {
  intro: string[]         // 简介分段，每段一个字符串
  developer: string
  publisher: string
  releaseDate: string     // yyyy-MM-dd
  platforms: string[]
  languages: string       // 如「简体中文 / 英语 / 日语」
  playTime: string        // 如「约 45 小时」
  guides: GuideBrief[]    // 关联攻略，见 4.3
}
```

### 4.3 攻略（列表项）

```ts
interface GuideBrief {
  id: number
  title: string
  category: string        // 攻略分类，如「新手攻略」
  views: number
  date: string            // yyyy-MM-dd
  author: string
}
```

### 4.4 攻略（详情）

```ts
interface GuideDetail {
  id: number
  title: string
  category: string
  gameId: number
  gameName: string
  gameCover: string
  gameSymbol: string
  author: string
  authorRole: string      // 作者身份，如「社区攻略作者」
  date: string            // 发布
  updated: string         // 最后更新
  views: number
  likes: number
  readMin: number         // 预计阅读分钟数
  tags: string[]
  summary: string
  content: string         // 攻略正文，Markdown 原文（对应后端 content_md）
}
```

> **已作废**：原 `sections: GuideSection[]` 结构化章节不再使用，
> 正文统一为 `content`（Markdown 字符串），由前端 `markdown-it` 渲染。

### 4.5 封面配色标识

`cover` 取值与 CSS 类名一致，前端按类名渲染渐变：

| 取值 | 效果 |
| --- | --- |
| `blue` | 深蓝 |
| `purple` | 紫 |
| `orange` | 橙棕 |
| `teal` | 青 |
| `indigo` | 靛蓝 |
| `sky` | 天蓝 |
| `gray` | 灰 |
| `green` | 绿 |

> 说明：当前封面不使用图片，改用「渐变色块 + 符号字符」，避免依赖外部图床、加载失败时也不影响布局。若后续要换真实封面图，只需把 `cover` 换成图片 URL 字段，样式层改一处即可。

interface UserProfile {

## 五、后端接口约定（已按 `docs/API契约.md` 对齐）

本节内容以 `docs/API契约.md` 为准，原稿中的 `list`、`/api/users/me` 等写法已作废。

**统一响应体**

```json
{ "code": 200, "message": "success", "data": {} }
```

失败时 `code` 非 200（400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在 / 500 服务端异常），
`message` 为可直接展示的中文。前端统一在 `utils/request.js` 拦截。

**分页**

请求 `page`（从 1 开始）、`size`（默认 10，上限 100）；响应 `data` 固定为：

```json
{ "code": 200, "message": "success",
  "data": { "records": [], "total": 42, "page": 1, "size": 10 } }
```

> **注意：是 `records`，不是 `list`。** 游戏库每页 6 条请显式传 `size=6`。

**鉴权**

登录后拿到 `token` 存 `localStorage`，之后所有请求带 `Authorization: <token>`（不加 `Bearer`）。
公开接口只有 `/api/user/login`、`/api/user/register`，其余都要登录。

**联调注意事项**

## 八、本地运行与自测清单

**启动**

```bash
cd frontend
npm install
npm run dev
```

默认地址 `http://localhost:5173`，端口被占用时以终端输出的 `Local` 地址为准。

**自测路径（建议按顺序走一遍）**

1. 首页搜索「星海」，确认跳到游戏库且关键词已填充、结果正确
2. 游戏库切换类型与标签、切换排序、翻页，确认列表与页码联动正确
3. 清空搜索词并选一个不存在的组合，确认空状态与「重置筛选」可用
4. 进入任意游戏详情，点攻略分类标签过滤，再点一篇攻略
5. 攻略页：点目录跳转、滚动看目录高亮与进度条、切字号、收藏后刷新确认仍在、点赞、复制链接
6. 攻略页点「向 AI 提问」，确认跳转 `/ai/chat` 且地址带 `q` 参数
7. 个人中心：编辑资料后取消（确认未保存）、再编辑并保存（确认提示出现）；切到「游戏」子标签确认 4 张卡片正常；取消一篇攻略收藏后回到攻略页，确认按钮变回「收藏攻略」；清空历史（确认二次确认生效）
8. 收藏闭环验证：在攻略页点「收藏攻略」→ 回个人中心「我的收藏」看是否出现该篇 → 点进去能回到同一篇攻略 → 取消收藏后再回攻略页确认状态已同步
8. 直接访问 `/games/999` 与 `/guides/999`，确认兜底空状态而不是白屏

**浏览器兼容**：Chrome / Edge 最新版验证通过；未适配 IE。
